## 1. 背景与目标
需冻结业务草案独立于 Agent 会话。本任务独立交付其职责，不承担下游模块实现。

草案 service、事件/证据 schema、测试。

临时 DB；可复现 canonical digest。基线 WSL2 Ubuntu 24.04 / Node 24 / 原锁文件；执行前检查 git status、HEAD、用户授权、依赖验收。涉及真实模型/副作用只在批准的隔离实例执行。

每一步完成后执行总体计划的三方语义对齐（PRD/总体计划、Issue/Plan、节点标准），偏差修复并复测；不得跨过未通过节点。详见 `plans/RETAIL-07-PLAN.md`。
