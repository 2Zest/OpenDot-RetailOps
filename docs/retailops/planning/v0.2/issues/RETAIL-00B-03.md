## 1. 背景与目标
Product Approval 仅 create_private_artifact；零售工具需要独立授权。本任务独立交付其职责，不承担下游模块实现。

## 2. 范围与明确不做
调查 consent/catalog/grant、参数绑定、exact-call、自动只读限制及取消；不写业务工具。不得修改未声明的模块、依赖版本、通用安全策略、既有断言；不连接真实商超写接口。调查任务不提前实现业务源码。

## 3. 输入
00B-01/R1、mcp-approval-store、durable-mcp-tools、external-mcp。实际启动时冻结上游 PR/commit、契约版本及证据路径；输入缺失或变更则停止并报告。

## 4. 输出
工具接入矩阵、授权模型、审批候选设计。

## 5. 环境与前置条件
只读源码及锁定依赖；隔离定向测试。基线 WSL2 Ubuntu 24.04 / Node 24 / 原锁文件；执行前检查 git status、HEAD、用户授权、依赖验收。涉及真实模型/副作用只在批准的隔离实例执行。

## 6. 依赖与上下游
- 硬依赖：无新增任务硬依赖；仍需总体计划获批。
- 直接下游：RETAIL-00C、RETAIL-00B-03V。
- 依赖仅在对应契约/证据通过且 PR 已合并（或经批准的只读调查输入固定）后满足；BLOCKED、NOT_RUN 不视为满足。静态调查可记录负结论，但不得因此放行依赖实际运行能力的任务。
